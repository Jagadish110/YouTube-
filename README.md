# YouTube channel pipeline

Saved pipeline for a faceless YouTube channel: script to voiceover to motion graphics to MP4,
all with open-source tools (Kokoro, HyperFrames, FFmpeg).

- `CLAUDE.md` has the step-by-step instructions.
- `videos/001-zepto/` is the first video, "How Zepto Got So Big So Fast".
- `./setup.sh` installs what a fresh machine needs.
